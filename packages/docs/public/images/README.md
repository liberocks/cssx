# Documentation assets

`protocol-grid.svg` retains the decorative grid geometry observed in the public [Protocol preview](https://protocol.tailwindui.com/) selected by the user. The pattern identifier, SVG namespace, and styling were adapted for a standalone image. This is a visual adaptation of the preview in the existing Astro app, not an installation of the downloadable Next.js template.

Interface icons use `@iconify-json/heroicons` (Heroicons, MIT).
