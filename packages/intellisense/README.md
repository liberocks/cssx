# CSSX IntelliSense

A small editor extension for static CSSX utility strings. It shows completion
and hover help in `cssx.create`, `sx`, and common `class` and `className`
attributes in supported source files.

The extension keeps its own CSSX utility list. It does not need a separate
utility list or language server.

To develop it locally, open this folder in your editor and press `F5`. Set the
publisher and version before you package it for release.
